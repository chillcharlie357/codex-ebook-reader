# Codex Reader 独立桌面版与双皮肤设计

## 目标

将现有阅读器从 LLM Wiki 单体仓库中完全拆出，形成独立的 Codex Reader 仓库和桌面应用；保留 TXT、EPUB、PDF、Markdown、HTML 的本地解析、进度和笔记能力，并提供可持久化切换的“Codex”与“阅读器”两套界面。

## 已确认约束

- 独立 GitHub 项目，不与 My-Wiki 共享代码目录、发布流程或产品叙事。
- Codex 皮肤以用户提供的 2048×1024 Codex Desktop 截图为基准，重点复刻三栏比例、系统字体、浅灰侧栏、白色正文、浮层式右栏、细分隔线和紧凑控件。
- 阅读器皮肤保留现有森林绿书卷风格、衬线正文和书籍封面卡片。
- 一级导航是书名，展开后二级导航是章节名；正文位于中央，元信息和私人笔记位于右侧。
- 所有文件与用户数据只在本机处理和保存。

## 视觉系统

### Codex 皮肤

- 颜色：画布 `#FFFFFF`、侧栏 `#F7F8F8`、选中层 `#ECEEEE`、正文 `#242424`、次级文字 `#8A8D8C`、边线 `rgba(26, 28, 27, .08)`。
- 字体：界面与正文优先使用 `-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`；数字与格式标签使用 `SFMono-Regular`。
- 布局：左栏 292px，中间自适应，右栏 320px；窗口控制只占左上角，中央和右栏从窗口顶部开始。
- 标志性细节：左上模式按钮直接复用 Codex 产品名下拉的视觉语法，点击即可切换到阅读器皮肤，不引入额外悬浮切换器。

```text
┌────── 292 ──────┬──────────── main ────────────┬── 320 ──┐
│ ● ● ●            │ 书名 / 章节          进度     │ 详情     │
│ Codex ⌄          │                              │ ┌──────┐ │
│ 导入电子书        │        章节正文              │ │书籍卡│ │
│                  │                              │ ├──────┤ │
│ 书名             │                              │ │元信息│ │
│  ├ 章节          │                              │ ├──────┤ │
│  └ 章节          │                              │ │笔记  │ │
└──────────────────┴──────────────────────────────┴──────────┘
```

### 阅读器皮肤

- 颜色：纸面 `#FBFBFA`、侧栏 `#ECEEEE`、墨色 `#242628`、森林绿 `#58766A`。
- 字体：界面使用无衬线系统字体，正文使用 `Songti SC` / `Noto Serif SC`。
- 布局：保留 43px 桌面标题栏和书卷式大标题，阅读版心 560–900px 可调。
- 标志性细节：竖排封面与首字下沉只在阅读器皮肤出现。

## 行为与数据流

界面模式以 `codex-reader-interface-mode` 写入 `localStorage`，启动时只接受 `codex` 或 `reader`，无效值回落到 `codex`。模式切换不改变书库、章节位置、笔记或阅读参数。现有 IndexedDB 数据结构保持不变，避免迁移风险。

桌面壳使用 Tauri 2：Vite 构建产物嵌入系统 WebView，文件解析仍由前端在本机完成。首个 Release 提供当前构建机对应的 macOS 安装包，并附带 GitHub Actions 工作流，为后续标签构建 macOS、Windows 和 Linux 产物。

## 异常与无障碍

无效模式存储值自动回落；导入失败继续使用现有明确错误提示。模式按钮提供可读的 `aria-label` 和 `aria-pressed` 状态；键盘焦点、移动端侧栏和 `prefers-reduced-motion` 行为继续保留。

## 验收

- 单元测试覆盖模式解析与持久化边界，并保留所有解析器测试。
- ESLint、TypeScript/Vite 构建全部通过。
- 在 2048×1024 桌面视口下分别截图 Codex 与阅读器皮肤，核对栏宽、顶部对齐、间距、字体层级和右栏卡片。
- 使用上传的《诡秘之主》TXT 验证导入、1,397 章节识别、章节切换和皮肤切换后内容不丢失。
